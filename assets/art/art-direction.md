# 纹章与誓约：美术规范 v0.11

Godot 4.7.2，桌面 2D 正交棋盘。参考画布 1440×1000，棋子约 64px，卡牌插画约 144×76px，指挥官展示约 190×140px。

主色：深靛蓝 #0C1720、玉青 #70D3BA、赤陶红 #F08B76、旧金 #D0B579、羊皮纸白 #E6E8DD。

风格：原创日式二次元，清晰墨线、明亮大色块和两级赛璐璐阴影；布料青绿、象牙白或赤红。所有角色明确25–35岁，动画化成年面孔，正常成年身材、约七头身。用露肩、开领、开衩、轻甲和首饰表达魅惑时装，职业武器与轮廓始终清楚。减少盔甲雕花与衣褶，避免写实皮肤、厚涂笔触、金属微纹理、过密饰物、灰暗中世纪背景及Q版头身。不复制现有游戏专有角色、标志或卡面。

艾琳：浅色短发、青绿披风和象牙金轻甲；维洛：深发赤披风、开领战衣和火杖；赛菈：深发、象牙鼠尾草绿露肩长裙、月饰与晶石杖。头像与全身图集保持同一身份、配色和服装。

六兵种通过发型、配色、表情和武器区分：蓝黑短发剑兵、黑马尾枪兵、赤发骑兵、金发精灵弓手、银发眼镜星术师、粉紫短发医师。不能只换发色却沿用同一脸和服装。

技术：肖像为横向三联图、低对比场景；棋盘全身像为透明背景三联图，每人独立方格。无卡框、文字、数值和标志。原图完整保留，Godot AtlasTexture实时分格。棋子在约68px全图视野仍保留职业徽记、阵营角标、攻击/生命；支持放大至280%。

地图使用连续草地/砂土/水面、连接道路/桥梁/河岸和少量立体地形装饰。画风参考研究见 docs/art-reference-study.md；六张12×10地图均为原创布局。旧Q版实验素材保留来源记录，不进入生产显示。

生成工具：运行时原生 imagegen，无 API CLI。

## 0.10 界面规范

深海军蓝作为屏幕底色，象牙白用于卡牌铭牌与人物情报，旧金作为结构边线和行动强调，青蓝/珊瑚区分双方。每个装饰对应信息：菱形是费用，圆徽章是兵种，底部短签是卡名，人物栏用横向生命条和晶石表达资源。战前以全身人物和真实地图预览建立主视觉；正式数值与文字不烘焙进生成图片。法术、环境、菜单与人物统一清晰线稿和两级赛璐璐阴影。

## 0.11 场景绘制规范

生产地图改为整幅日式战棋环境绘制，统一高位正交视角、左上日光与清晰地貌轮廓；草地/沙地/石铺装和水岸连续过渡。森林河谷明亮青绿，沙漠遗城暖砂金，山隘冷灰岩与松林，古堡象牙石与草木，港口青蓝水道与白石堤岸。减少铺满格子的装饰，部队行走区保留低对比细节。

图像必须遵守真实12×10地图的地貌中心与通路，不能在开放格增添树林、岩山或悬崖。桥梁必须跨过实际水格，平台须有可占领的平坦顶部；建筑留出棋子驻守中心。正式图片不包含文字、网格、棋子、数值或UI。自然树冠/投影可以跨格边，精准规则用原生G网格与行动高亮表达。

六幅原图均完整保存并核验来源哈希；只在Godot设置缩小纹理层级和运行时叠层。动态造路/筑垒采用原生地面补片与物件，不用脚本改生成图像素。完整实际提示词、父图及导图由battlefields/sources.json指向，规则叠图和实机核对见docs/map-art-audit.md。
