工具：原生 image_gen；未使用 API CLI；运行时未公开底层模型名。原图保持原始 PNG，所有裁切由 Godot AtlasTexture/UV/cover 实时完成。

## menu

用途：战前部署背景。生成图 1536×1024。

提示词核心：原创奇幻战棋世界的破晓城堡与河谷，常青森林、双桥、古旧石制城墙与青绿旗帜；中心 55% 保持较暗、低细节，以容纳原生菜单；手绘油画/水粉质感，暖金色左上主光、冷靛蓝阴影、玉青河水，禁止文字、卡框、角色、格线、标志和现有游戏场景复制。

完整英文提示词曾随原生工具调用保留在本聊天；此文件保存用途、约束和可复用风格，不声称是逐字提示词备份。

## units

参考：menu 的风格与配色。用途：统一的 3×2 兵种肖像图集，1536×1024，按每格 512×512 使用。

顺序：步兵剑士、重甲枪卫、骑士与战马、森林精灵弓手、赤焰法师、晨光医师。

约束：每格独立暗色场景；成年人；脸部大、武器可辨；同一左上暖光与冷色环境光；实用盔甲、青绿布料与旧金金属；无文字、边框或外部水印；主体不跨格。弓手实际产物呈中性精灵外貌，保留为未限定性别的“暮林游侠”。

## heroes

参考：units 的材质、画风和光照。用途：3×1 指挥官头像图集，实际输出 2172×724，按每格 724×724 使用。

顺序：艾琳（浅发短发、青绿披风、金甲、剑柄）、维洛（赤红披风、黑金甲、余火）、赛菈（深发、月形头饰、象牙与鼠尾草绿长袍、木杖晶石）。

目标：与士兵属于同一原创世界，头肩肖像在 64px 下可辨；无文字、标志、卡框、裁断头部或已有游戏角色复制。

前两次单人肖像调用长时间未返回，已终止；不将其计为交付资产。成功交付为上述三人图集。
