# 叙事基线与章节制作顺序

## 已确认方向

群像战争史诗，带人物羁绊与适量感情线。角色与设定原创，玩法参考不延伸为借用其他作品的角色、世界或剧情。现有九人年龄26–32，具名队长代表军团，重复打出的部队牌代表受其统领的不同小队，不制造剧情人物分身。

采用`chinese-novelist`写作流程，既有项目不重新问答。续写前读取[写作基准](narrative/writing-bible.md)与[写作进度](narrative/writing-plan.json)，先设计人物欲望、阻力与变化，再逐场改稿。[本轮编辑记录](narrative/editorial-review.md)列出具体问题和处理；测试与字数不替代读者判断。

## 世界事实

共誓历317年，长昼之灾过去17年。澜河连接守望议庭、赤曜诸城与暮林盟社；三方互相依存，也各有灾后债务。新的调候命令互相矛盾却都带合法印章，粮食、交通和水源开始被当作战争工具。

纹章记录有见证的承诺；誓令卡是部队调度与魔力调用的载体。邻接增援由前线接应，局部施法由纹章定位，天气牌改变共同环境。魔法不能判断一份合法命令是否正当，也不能抹去伤者、后勤与民众的代价。

艾琳要回答法度何时需要改变；维洛要回答自己是否愿意受他要求别人的规则约束；赛菈要回答维护家园是否允许把后果留给下游。六队长有各自的生计、旧伤与关系，不能只担任主角立场的传声筒。

## 写作与接入纪律

- 每场对话有明确当下需求、分歧和变化；既写失败者也写需要承担胜利后工作的人。
- 选择先给足信息，再说明玩家正在决定什么。结果允许复杂，不能依靠事后隐藏事实惩罚正常判断。
- 感情线双方均为成年人，自愿且可不推进；不将战争救援或医疗照顾设为交换亲密的条件。
- 技能数值来自战斗数据，剧情不复制硬编码数值以免失配。故事可解释身份和习惯，但不能随意赋予关卡中不存在的能力。
- 逐章先完成节点与关卡闭环，再扩充正文、美术和支线。每章保留可读草稿、接入数据与验证证据的区别。
- 文本由AI辅助创作并逐段编辑自审；最终仍需外部阅读与试玩反馈。完整正文发行时如实纳入AI预生成内容披露。
