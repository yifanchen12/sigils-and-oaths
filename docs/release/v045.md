## 新玩法

- **先遣与包夹。** 二费「灰岸传旗骑」部署当回合能移动一次，仍待下回合才能主动攻击或使用技能。二费「双岸夹签」在两支普通友军贴近目标时伤害从 2 升到 4。三费「落单追令」对身旁无援的敌军造成更多伤害。
- **撤回与归队。** 四费「红灯担架」向己方指挥官方向撤回一支部队最多两格，治疗并解缚。低费「残旗归册」把合格的阵亡部队牌拿回手牌。五费「灰营点卯」与九费「雾岸集结」把符合费用上限的阵亡部队满血部署到选定的相邻空地，返场跳过进场效果。
- **伏设与反刺。** 伏设从手牌支付费用。地格可用于截步和拆盾。护军陷阱能在援护之后对实际承受普攻的友军生效。部分陷阱还会反刺攻击者，或在敌方普攻和术击之间等待先发生的一次。
- **工事与天气。** 七费「扼道立栅」把一片陆地改为工事，为改造地上的己方部队加护盾。双方都能利用工事的地形防御。「风旗开港」带来全场疾风，同时为己方指挥官附近的部队解围。

四张十费牌分别是先遣步兵「破晓掌旗卫」、局部群体破盾法术「静潮断甲令」、护军反伤陷阱「反潮总闸」和救援天气「风旗开港」。单体与范围法术仍需要友军提供局部施法范围。 [十费卡牌图鉴](../screenshots/v045-tidegate-ten-mana.png) · [七费工事实机预估](../screenshots/v045-tidegate-fortification.png)

## 从哪里开始

战前菜单可分别选择己方和对手的预组。「折潮快旗」用先遣和站位抢节奏。「回港后备军」用撤回、护军陷阱和阵亡返场维持阵线。两套牌均为 30 张，放在一起覆盖全部新牌。组牌界面和图鉴均可选「潮门后备」，再按费用筛选。

Windows x64 包解压后运行 `SigilsAndOaths.exe`。请将 PCK 与 EXE 保存在同一目录。 [GitHub Release](https://github.com/yifanchen12/sigils-and-oaths/releases/tag/v0.45.0-dev)
