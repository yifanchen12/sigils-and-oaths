# 纹章与誓约 0.46.0-dev · 盐布巷护送

第七章《未送达的名字》增加一段可跳过的战役支线。北街学堂收到沈芦的求援，米芮和伊瑟要在涨水后的染坊带出蒋釉。新绘制的染坊场景和盐布巷战场共用靛布、石渠和西侧低廊的地标。 [剧情实机](../screenshots/v046-saltlane-story-small.png) · [地图实机](../screenshots/v046-saltlane-battle.png) · [美术来源](../../assets/art/narrative/saltlane-source.md)

- **低桥往学堂。** 担架行至 C3 低廊，时限 8 轮。第八章初始手牌会加入「红灯担架」。
- **高桥往窑场。** 担架行至 N3 石阶，时限 9 轮。第八章的己方指挥官开场获得 3 护盾。
- **失守后选择。** 可以重试，也可以撤回主线。撤回会留下不同的后续对白。

这场战斗使用 16×12 地图。金框标记的担架队负责移动与急救。它到出口立即成功，固守格上的普通友军不能代为送达。担架队或己方指挥官倒下即败。只要担架队存活，击败敌方指挥官也会解除封锁。 [实机送达](../screenshots/v046-saltlane-victory.png)

## 验证

三条固定路线从新战役走到「共掌一灯」。跳过支线完成 15 场，选择低桥或高桥各完成 16 场。两次护送分别使用 27 和 23 个合法行动，均中途存读档并在对方指挥官仍存活时实际送达。测试对战另换 16 个固定起手种子，低桥 6/8、高桥 7/8 送达。真人难度待验证。 [连续战役和对局记录](../saltlane-playtest-v046.json)

Windows 原生界面完成窑场护送的点击操作，并验证败退按钮。第七、八章共 459 个正文页面在 1008×700、130% 字号下通过排版检查。旧版 0.45.0-dev 的第七章阅读位置和第八章战中局面可正常恢复。 [排版结果](../narrative-native-ui-v046.json)

本版增加 2,485 个可达的去重正文汉字。十八章与档案合计 115,970 字，单路正文为 85,680 到 88,205 字。 [正文统计](../narrative-audit.json)
