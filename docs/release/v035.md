# 纹章与誓约 0.35.0-dev · 北岸有回信

Windows x64 开发预览版。解压 ZIP 后运行 `SigilsAndOaths.exe`；界面与剧情目前为中文。游戏是原创单机卡牌战棋，包含十一章战役、六兵种、三指挥官、32种可组牌、四套预组牌、地格与受击陷阱、局部施法和90秒行动回合。

本版新增第十一章：艾琳在北岸红瓦屋和旧渡头听到两位亲历者的证词，确认父亲最后一次救援和安葬处；塔门内阀裂纹与北岸备件成为下一步的具体目标。新增两张原创叙事场景，第七章同行关系与第九章三种治理方案影响对白。第十章双桥塔门战规则保留。

验证范围：第十一章119段条件正文全部在 Godot 原生界面渲染；三份此前真实塔门胜利存档均通过本章并在独立进程恢复终页；固定模型路线从新战役连续十一战获胜，进入第十一章终页。十一章和档案共81,355个去重正文汉字，该固定路线实际读到60,044个。三处旧关玩家使用公开信息测试策略，以上测试不代表真人难度、所有战斗分支的胜率或完整结局。[详见编辑与验收记录](../narrative/chapter-11-review.md)。

这是开发预览版，尚未达到 Steam 发行条件。真人完整试玩、平衡、全篇结局、单路线十万汉字和外部机器验证仍待完成。AI 辅助制作的插画与叙事正文在开发时固定，游玩时不调用实时生成服务。
