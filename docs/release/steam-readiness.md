# Steam 发行准备状态

最后核对：2026-11-06。当前源码为0.14.1-dev，最新原生图形验收里程碑为0.13.0。**没有提交Steam审核，也未达到完整战役发行条件**。

## 已有构建内容

- Windows Godot工程，单人对AI遭遇战；六战场、三指挥官、六兵种技能、24种可组牌。
- 九角色三帧关键动作、局部施法与伤害预估。
- 共誓档案：18篇、52段、5,558个去重中文正文汉字；人物、世界与地理入口均接入。不是主线战役，也没有计入尚未制作的故事。
- 首章候选：6,964正文汉字、八条选择组合、每路线两场战斗；剧情与检查点存储通过纯逻辑/跨进程检查，菜单已接线但原生窗口与正常难度通关待验。未合入已验收字数。
- 完整战斗快照与v1存档迁移通过纯逻辑及独立进程恢复验证；恢复牌序/技能/援护/地形/天气/计时/RNG并继续行动。菜单/正常退出/AI恢复已接线，原生退出与返回流程仍待验。

## 开发门槛

- [ ] 首章：对话与选择、战斗、结果、退出重开恢复。
- [ ] 全部章节、支线与结局可达；正文至少100,000汉字，报告全部分支与单路线阅读量。
- [ ] 世界/人物连续性审读、重复内容检查、地图/肖像/卡面/剧情视觉统一审查。
- [ ] 战役存档、损坏恢复、重试、教程、设置、音频与阅读便利功能。
- [ ] 规则回归、逐章通关、分层平衡诊断；人工完整试玩与外部试玩问题修复。
- [ ] Windows独立发行导出与干净目录启动、存读档、完整通关、性能与长时间运行测试。
- [ ] 字体、音乐、音效、依赖、插画来源及发行权利清单逐项核查。
