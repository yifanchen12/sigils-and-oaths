# 0.56.0-dev 平面战场与施法演出

从备战页进入「断脊隘口」「日陨遗城」或「古堡棋庭」，可以在新的平面地图上直接开战。星火箭先从一名施法距离内的友军处亮起，再飞到敌军所在的格子。枪卫援护时，盾光会伸向相邻友军；敌方伏设时，守方首次看到具体地点是在陷阱公开触发时。 [七段实机演示](https://github.com/yifanchen12/sigils-and-oaths/releases/download/v0.56.0-dev/SigilsAndOaths-0.56.0-dev-Casts.mp4) · [Windows 下载](https://github.com/yifanchen12/sigils-and-oaths/releases/tag/v0.56.0-dev)

## 地形和镜头

- 断脊隘口的板岩相连成脊。弓手能从坡面上高地，借额外一格射程攻击对面的敌兵。 [隘口实机](steam/gameplay/09-ridgepass.png)
- 日陨遗城的行道部分埋在沙中。带台阶的石门可给守军提供两点防御，用手牌开辟军道会移除该格的工事。 [遗城实机](steam/gameplay/10-sunspire.png)
- 古堡棋庭用铜顶拱廊围住庭院，风玫瑰所在的格子可以通行、部署和伏设。 [古堡实机](steam/gameplay/11-citadel.png)

六张自由对战地图现在都有可编辑的 Blender 工程，按各自的 12×10 战棋格建模并渲染为 2160×1800 平面底图。运行时沿用 Godot 的二维棋盘、缩放和拖动。战役专属地图沿用各自布局。重新打开六份模型后核对了全部 720 个格心的投影。三张新地图还通过了 385 项 Windows 实机检查，覆盖从备战页开局、拖动缩放后的 360 个格心和实际走位出牌。 [建模源文件](../../assets/art/model_sources) · [投影核对](../../tools/check_battlefield_models.py) · [实机操作检查](../../tests/test_highlands_relief_ui.gd)

## 战斗演出

火焰、疗愈、护盾、冰缚、伏阵和增援使用六幅原创透明特效图。近身技能从行动单位出手，卡牌定向施法从能覆盖目标的友军起势。两用军令随友军或敌军目标切换演出，范围标记取自实际分支。天气变化掠过全场。兵种主动、指挥官技能和七费以上的公开手牌会短暂显示原画和名称。设置中的简化动效保留静态图标、目标标记和数字。 [命中瞬间](steam/gameplay/12-cast-impact.png) · [图集与制作记录](../../assets/art/battlefields/highlands-and-casts-source.md)

10.5 秒演示截自七次普通对局中的合法行动，按星火箭、战地急救、铁壁援护、锚索伏阵、烈焰裁决、骤雨将至和十费镜道和约的顺序剪在一起。录像取每秒 24 帧的游戏画面并裁出战场，文件为静音 H.264。战斗特效实机检查覆盖六兵种、三位指挥官、两用牌的攻守分支、简化动效和非法目标。另测了角色动作、最终一击的胜负界面、敌方伏设的保密与触发。 [录制程序](../../tools/capture_store.gd) · [实机特效检查](../../tests/test_cast_visuals.gd)

## 双潮军令
