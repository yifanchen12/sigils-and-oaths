# 纹章与誓约 0.41.0-dev · 前线扩牌与三盏灯

Windows x64 开发预览。解压后保留同目录的 `SigilsAndOaths.exe` 与 `SigilsAndOaths.pck`，双击 EXE 启动。游戏界面和剧情为简体中文。

- 新增 24 张 1–10 费原创牌，包括进场效果、群体法术、从手牌伏设的陷阱和环境牌。现在共 58 种可组牌，另有 1 种对局生成牌。
- 新增逐岸先锋、断阵重术和灯曜守队三套 30 张预组。图鉴支持筛出前线新卡，组牌界面显示完整费用曲线，战场标出局部法术范围。
- 十八章战役接入共掌一灯、各守一渠、留水过冬三个可保存的结局。
- 新增 16×12 三灯撤离道和 16 轮接力战。两种开局分别把疾行军令或回誓屏障加入手牌。
- 新增 163 个可达正文页面、原创战场图和结局晨景。恢复 0.40 东桥和更早战斗存档的兼容性。

新牌通过 148 项规则检查。原生窗口验证了图鉴筛选、复制预组、费用曲线与十费施法。36 场普通资源的 AI 对局共执行 7,705 个合法行动，24 张新牌均打出过，天炉坠火共 19 次。断阵重术对四种预组共 22 胜 2 负，真人强度需继续确认。[逐场结果](https://github.com/yifanchen12/sigils-and-oaths/blob/codex/unit-skills-combat-animation/docs/warfront-matchups-v041.json)
