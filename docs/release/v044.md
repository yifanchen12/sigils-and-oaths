# 纹章与誓约 0.44.0-dev · 散阵与反制

Windows x64 开发预览。解压后保持 SigilsAndOaths.exe 与 SigilsAndOaths.pck 在同一目录，双击 EXE 启动。

- 「实战教程」增加「散阵与术击反制」。伏设湿帷潜护，在多个合法格中选择一条撤离路线，承受守军的十费天炉坠火，再收回并重新部署受伤枪卫。四节教程都可单独进入。
- 断阵重术增加侦察、架桥和破盾选择，削减部分清场、补牌与高耐久部队。八费澜潮冲阵和十费天炉坠火仍在预组中。
- 灯曜守队减少重复的随军医、群疗与灯夜，加入临桥木架与三巡接灯。0.43 发行版创建的战中快照可以恢复，包含开局牌表、牌序和已结算行动。
- 游戏关闭时先停音乐和战斗音效，并完成存档流程。开发工具可以从已验收的 Windows 包生成 SteamPipe 内容目录和预览模板。 [Windows 打包说明](https://github.com/yifanchen12/sigils-and-oaths/blob/v0.44.0-dev/docs/release/steam/windows-depot.md)

新旧版本在六张地图和三位指挥官上成对测试，共 264 场、66,421 次合法行动。断阵重术由 56/72 胜变为 32/72 胜，两张高费法术在新版样本打出 114 次。灯曜守队从 32/60 胜变为 35/60 胜，对回灯前哨仍有优势。真人平衡仍待验证。 [逐场结果](https://github.com/yifanchen12/sigils-and-oaths/blob/v0.44.0-dev/docs/balance-v044.json)

原生 Windows 界面和教程共 377 项检查通过，十八章固定路线走完 15 场战斗并到达结局。 [散阵教程实机画面](https://github.com/yifanchen12/sigils-and-oaths/blob/v0.44.0-dev/docs/screenshots/v044-counterplay-drill.png)
