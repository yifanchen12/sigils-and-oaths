# 0.55.0-dev 暮林边境与碧潮港湾

在备战页选「暮林边境」，可以从林边绕过两块断岩，把弓手送上中央高地。选「碧潮港湾」，北面是三孔石拱桥，南面是带绞臂的木吊桥。东西岸各有工事和遗迹，两座桥都能过兵。六张自由对战地图中，暮林、港湾和双桥河谷现有整图 Blender 模型，游戏读取每张模型渲染出的 2160×1800 底图。 [暮林实机](steam/gameplay/01-local-spell.png) · [港湾南桥实机](steam/gameplay/08-harbor-crossing.png)

「临桥木架」在水上按两岸的方向铺板。用它占一处港湾泊位时，该格换成同一相机拍下的空水面，再铺木桥。相邻泊船仍留在原处。部队可以在桥建成后踏上新路。 [港湾模型](../../assets/art/model_sources/harbor-relief-v1.blend) · [暮林模型](../../assets/art/model_sources/greenwood-relief-v1.blend)

## 已验证的操作

- 从硬盘重新打开两份 Blender 工程，逐格核对相机投影与地图数据。暮林有 997 个可编辑对象，港湾有 848 个；两份工程使用本地程序材质，模型和材质均随源文件提供。
- Windows 实机完成两张新地图的 273 项检查。备战选图后逐一核对缩放、拖动下的 240 个格心，点选弓手登高获得第 4 格攻击距离，预览并打出局部法术，再用军道牌改变林地。
- 部队分别踏上石拱桥和木吊桥，并走上从手牌搭出的新桥。四个泊位逐一比对渲染像素，检查桥栏外的水面和船影。既有双桥河谷另通过 131 项实机检查，地图资源通过 50 项回归检查。 [交互与画面测试](../../tests/test_frontier_relief_ui.gd)
- 标准难度从头走完一条十八章路线。选军道开局、先救济、在盐布巷接应学舍；16 场战斗共执行 3,434 次合法操作，中途保存并读取，最终到达剧本结局。测试中有五处关卡使用按可见局势决策的专用策略，结果覆盖这条自动路线。另行完成 12 场自由对战及 134 项效果预览检查。 [连续战役验证程序](../../tests/benchmark_campaign_continuous.gd)
- 港湾截图取自「逐岸先锋」对「均衡军势」的正常资源对局。种子 5501 经 57 次合法操作到第 7 轮，南桥的医师正预览对东岸枪卫的普通攻击。暮林的十费法术和牌库征召、河谷的桥头交锋也以当前画面重新截取。 [截图清单](steam/inventory.json)

Windows x64 预览提供简体中文 MSI 和便携 ZIP。解压 ZIP 后，双击同目录的 `SigilsAndOaths.exe` 即可打开。 [下载本版](https://github.com/yifanchen12/sigils-and-oaths/releases/tag/v0.55.0-dev)
