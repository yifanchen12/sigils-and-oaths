# 纹章与誓约 0.48.0-dev · 战前军需

第四章起的 20 场战斗加入战前军需。每关列出三张适合当前任务的牌。可以沿用原定军势，也可以选一张，替换战前界面上写明的起手牌。新牌在开局便可见，照常支付费用，战役也能打出「潮门后备」和「堤灯军令」的卡。 [战前预览](../screenshots/v048-requisition-selected-small.png) · [实际起手](../screenshots/v048-court-hand.png)

| 战斗 | 可用军需举例 |
| --- | --- |
| 第四章返潮靠岸 | 用二费「灰岸传旗骑」换下「烈日天穹」。先遣骑兵部署当回合即可移动 |
| 第六章棋庭 | 用「洪线告旗」、十费「破晓启洪闸」或十费「堤灯主刀官」换下「移形军令」。前两张能预告一片地格，医师进场可以群疗 |
| 第七章盐布巷 | 低桥与高桥各有独立的接应选项。「红灯担架」可牵回受伤或被定身的部队。关卡原有的开局援助也会发放 |
| 第十二章北岸 | 在共同轮值线可换下「铁壁枪卫」，带上可抵挡普攻或术击的护军陷阱「苇钱备援」 |
| 第十六章东桥 | 可用灯夜、公开军令或群疗医师换掉「锚索伏阵」。提前拿到高费牌也意味着少一张早期伏设 |
| 第十七章三盏灯 | 先送灯手路线可在两张旧骑兵中换一张低费先遣，护住担架路线可以选援护或延迟群疗 |

军需选择当场保存。进战后，退出重开会恢复原手牌顺序、战局和计时。战败后可沿用已选军需直接重试，也可回到原定军势或另选一张。打赢或撤出支线后，下次的简报按新关卡重新提供军需。0.47 的战中档可直接读回并保留原始套牌。 [旧档样本](../../tests/fixtures/v047-court-encounter.json)

## 验证

80 场同种子对照共执行 14,890 个合法行动。60 个换牌方案中，53 项实际出牌，41 项获胜。20 场战斗都至少有一项军需在这轮对照中获胜。先送灯手路线携带「灰岸传旗骑」时以 28 步完成，原定军势对照为 120 步。真人手感与各选项的平衡仍待试玩。 [逐场对照](../requisition-playtest-v048.json)

两次自动流程都从第一章完成十八章、十六战，到达「共掌一灯」。学堂线使用原定军势，窑场线选择了 11 次军需，其中 10 次在对应战斗实际打出。后者在东桥部署了十费「堤灯主刀官」并获胜。部分既有关卡的玩家侧使用基于公开信息的测试策略。 [连续战役摘要](../requisition-playtest-v048.json)

Windows 上使用三个独立进程依次点选军需、重开后率军出征、再次重开进入战中。1008×700 窗口、130% 阅读字号下，全部 60 个军需选项的卡牌规则与战斗按钮通过显示检查。军需桌的原始图、提示词及来源已留档。 [美术来源](../../assets/art/narrative/quartermaster-desk-source.md)

Windows x64 版解压后双击 `SigilsAndOaths.exe`。请将 PCK 与 EXE 留在同一目录。 [GitHub Release](https://github.com/yifanchen12/sigils-and-oaths/releases/tag/v0.48.0-dev)
