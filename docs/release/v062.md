# 0.62 · 撑渡枪夫上阵

在「自由对战」选「双桥河谷」和「回灯前哨」。把三费的撑渡枪夫部署在友军身侧，棋盘上能认出原卡的灰胡子、白头巾、铜甲和系红布的月牙钩枪。入场时他压低重心援护；随后移步、出枪、收势，始终是同一个人。

81 张部队牌各自对应一幅全身棋子。按原卡新绘了 75 张扩展部队棋子，保留了 6 张基础部队的全身图。比如守桥老枪保留深蓝鳞甲和长辫，撑渡枪夫穿铜甲，黑鸦枪哨则两人执枪守在同一格。可从所属部队和装备辨认同一兵种里的不同牌。

撑渡枪夫有站立、架枪援护、出枪和收势四幅独立原画。其余 74 张扩展部队用各自的立绘表现移动、蓄力和出手。卡面、棋盘、主动技能立绘和战斗快照按同一张牌取图。旧战斗存档已有卡牌编号，读档后即可显示这版棋子。 [美术来源与提示词](../../assets/art/pieces/production.json)
