# 0.54.0-dev Windows 安装版

下载 Windows x64 MSI，双击后可选择安装目录。安装面向当前 Windows 账户，默认使用 `%LOCALAPPDATA%\Programs\Sigils and Oaths`。完成后从开始菜单搜索「纹章与誓约」。在 Windows 的「已安装的应用」里可以卸载。 [GitHub 预览版](https://github.com/yifanchen12/sigils-and-oaths/releases/tag/v0.54.0-dev)

便携版在同一发布页提供。解压后把 `SigilsAndOaths.exe` 与 `SigilsAndOaths.pck` 留在同一目录，双击 EXE 即可打开。两个下载文件均附 SHA-256 校验值。

## 安装与存档

- 安装版、便携版使用同一个游戏数据目录。战役进度及战中快照、自定义牌组和偏好设置位于当前用户的 AppData。卸载、重新安装与覆盖升级均可保留这些文件。
- 升级使用已安装版本的目录，安装完成后沿用同一个开始菜单入口。Windows Installer 阻止用较旧版本覆盖较新版本。
- GitHub 的 MSI 与 ZIP 包含相同的游戏文件。SteamPipe 目录使用这些游戏文件和平台自带的安装流程。 [微软的当前用户安装说明](https://learn.microsoft.com/en-us/windows/win32/msi/installation-context) · [SteamPipe 构建文档](https://partner.steamgames.com/doc/sdk/uploading)

## 构建与验收

以 WiX Toolset 和 UI 扩展 5.0.2 构建 MSI。两者只在构建时使用。安装包的简体中文对话框、应用图标、文件和快捷方式由工程的安装定义指定。 [WiX 5.0.2 发布记录](https://github.com/wixtoolset/wix/releases/tag/v5.0.2) · [安装定义](../../tools/windows_installer.wxs)

在 Windows 上运行以下命令，准备工程内构建工具。需有 .NET SDK 和项目使用的 Godot 导出环境。

```powershell
$wixRoot = (New-Item -ItemType Directory -Force '.tools/wix-5.0.2').FullName
dotnet tool install wix --tool-path $wixRoot --version 5.0.2
$ui = Join-Path $wixRoot 'wixtoolset.ui.wixext.5.0.2.nupkg'
Invoke-WebRequest -UseBasicParsing -Uri 'https://api.nuget.org/v3-flatcontainer/wixtoolset.ui.wixext/5.0.2/wixtoolset.ui.wixext.5.0.2.nupkg' -OutFile $ui
dotnet nuget verify $ui --all
Add-Type -AssemblyName System.IO.Compression.FileSystem
[IO.Compression.ZipFile]::ExtractToDirectory($ui, (Join-Path $wixRoot 'ui-extension'))
.\tools\build_release.ps1 -WindowsInstaller
```

安装测试从 0.53 便携包的实际游戏规则写入战中存档、自定义牌组和偏好设置。测试流程检查早期安装包、正式包在同一路径升级、较旧版本拒装、卸载、重装、三次独立启动及原数据读回。它会在当前用户留下测试日志，并清理本次创建的程序注册与开始菜单入口。脚本在发现此游戏已安装时会拒绝使用该账户做测试。 [验收脚本](../../tests/test_windows_installer.ps1) · [战中存档探测](../../tests/installer_profile_probe.gd)
