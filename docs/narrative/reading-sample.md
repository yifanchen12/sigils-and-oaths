# 两章改稿选读

摘自0.15.1-dev可运行正文。以下只选两个连续场景，完整分支以游戏JSON为准；没有启动游戏窗口。

## 第一章：三方初遇（军道路线）

“带走之前，先问出钱的人。”
维洛从棚里出来，拿两指夹着船货保单。伊瑟跟在后面，想提醒他，话没赶上。赛菈没移开手，艾琳也没让路。维洛停在两人中间，终于把保单摊平。

**维洛：**

口粮的钱，有我的一份。种粮你可以守，车先别带走。我等这批货等了五天，今天还要替它付第二遍钱？你们谁愿意，先写个名字给我。

“欠款找出资的议会。”艾琳说。
“我会找。现在先找我的货。”
伊瑟在两人之间放下册子，压到保单一角。维洛伸手去抽，目光落在册子边的附印上，忽然停住。艾琳看见了。

**艾琳：**

这是军道上的封锁令原件。号与我们的令相同，晚签一天。赫姆已被带往东岸。我来这里接人，也得让这些车进仓。

伊瑟把附印举到光下。印边有一个细小的缺口，像被刀尖敲掉过。
“旧炉坊的模子。”他说。
维洛伸手把纸压回桌上，力道太大，杯里的水晃出来。
赛菈看着那只手：“你刚才说，你只来找货。”

**伊瑟：**

这道印早停用了。能认出图样，不能只凭它认人。我得看原始回执……维洛，手松开，你把印角挡住了。

米芮把一只空碗放到桌上。
“你们还要多久？”
艾琳往棚外看。男孩带来的人坐在车轮边，其中一个走不到锅旁，正由洛恩背过来。
维洛先把保单收起。赛菈的手仍压着种粮车钥匙。

## 第二章：旧雇主

守桥战后，护运兵认出了维洛。

断了旗杆的护运兵坐在桥栏边，洛恩替他递布。他没接，却冲维洛喊了一声执政官。
维洛脚步停了。
“你知道他们是谁。”艾琳说。
“我雇过。”
“什么时候？”
“还没结清钱。”

护运兵指向东岸灰屋，门口挂着秤，后院通往守备营。那里便是交接所。两名短甲兵正往车上搬柜子，另有人把几条长凳绑到一起，给不能快走的人坐。河门守备官今晨要求留存的回执，就在柜里。

**维洛：**

那笔钱是诸城欠他们的。我担了保，他们拿它养人。现在谁接下欠款，谁就能给他们活干。我会去谈。你要骂，等把柜和人留下再骂。

艾琳从他身边走过去：“这回一起。”
维洛想拦，赛菈将路边捡起的调运铅封放进他掌心。缺口落在麦穗下，与昨夜那张草图同样歪了一点。他把铅封握住，没有再走到前面。

## 第三章 · 旧井口

以下为游戏正文原文节选，完整场景及两种路线以游戏为准。

钟叔把灯挂上铁环，照出石后的旧灰。芙蕾伸手摸了一下，没蹭掉。
“最后是谁叫撤？”洛恩问。
“我。”
他不再往前问。钟叔却说：“你只叫了一次。我们等你再叫，你一直没有出声。”

我听见里面还有两下。我想，也许把绳放回去，能再下一个人。可上头的架已经在响。我叫撤，等你们拉我上去，又叫你们别封。

我封的。你把灯扔进泥里，说还能下去。后来你进了枪卫，我就知道，你还想找个能替你下第二次的人。

芙蕾猛地转头，右肩抬到一半又放下。
“我的队员不替那两声下井。”
钟叔也看见她收肩，问是不是当年的伤。
“后来当兵伤的。别把两件事搅在一起。”
他低头拨灯芯，没再追问。

洛恩站在第五环外，把原本想搭过去的手收回盾带。芙蕾从枪上解开一小截旧工衣，露出内侧缝过的线。
“你给我的。”她对钟叔说，“救援队撤完，剩下这件。我当时以为，拿走就能少回来一次。”
钟叔没接，让她自己收好。
