# 最后战役段落工作纲要

0.41 已接入第十七章《三盏灯》和终章《水到门前》。第十六章留下的修阀、索债与临时送桶依次得到交代，最后三种治水结局分开兑现。下文保留终局的编辑约束。[剧情与规则验收](finale-review.md)

1. **先兑现两种修阀选择。** 重铸要实际付两日炉钱、班次与材料；短套只能做低压复试，漏就拆。北岸替件及一车已磨面粉必须有到货与未到货的可核事实。不能在下一页忽然宣布塔修好了。
2. **把人放到选择的对立面。** 桑岚有权拒绝危险的高压测试；祁栎有权要求城里承担磨坊延误；秦婶可以不接受“以后会有水”的保证；维洛不能替护卫写欠饷；赛菈需向林社解释上游少了什么。每场戏至少有一个人改变行动，而非轮流宣言。
3. **终局冲突源于现有三方。** 棋庭只能保道路、不能用旧紧急令夺塔；赤曜有材料与工钱债；林社掌上游取水；日陨居民需要稳定供水。若设计新战斗，须由已建立的具体争议和拒绝让步导致，胜利只解决战场能解决的事。
4. **结局至少有三种可比较的制度与人际后果。** 共同轮值、分段旁路、封池一季应在实际供水、维修工资、上游水位和居民返家上有不同代价；对白承接先前关系选择，不强制固定情侣。艾琳父亲身故已证实，无名石是否刻名由家属决定。
5. **完成标准。** 每条实际可读路线正文接近或达到十万汉字，故事有收束；新战斗可用合法行动过关、败局和重试成立；从新战役到结局有至少一条连续实机通关记录。外部阅读、真人战斗体验、跨机器安装与Steam商店验收另行验证。

后续人物支线需要带自己的欲望和后果。让洛恩和芙蕾处理港口与断脊的不同责任，让莉希与希弥兑现信路上的承诺，让米芮和伊瑟承担病房与观测各自的风险。先确认玩家可在游玩中读到人物前后文，再把这些篇幅计入单路线正文。
