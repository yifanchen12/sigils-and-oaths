# 三盏灯与水到门前

第十七章在雨夜撤离。重铸路线已有低压结果，短套路线因渗漏拆下。水来自上涨的外渠，北井供水独立。城巡队为给高街的车留路而挡住西街担架，直到接力战解封。莉希先送灯和芙蕾先护担架分别加入疾行军令和回誓屏障。结算按 E4、I6、L8 的顺序进行，每个己方新回合至多确认一站。三站均完成或击退敌方指挥官即可获胜，16 个完整轮次内仍未达标会进入重试。

终章用高街返家、曲汀账册、旧渡口和营地四处场景交代前线后果。共同轮值在复测后短时低流量供水，分段旁路保留主塔封停并承担材料与工钱，封池一季把开支移向安置并留下工坊停工。玩家能看到三条路各自的第一轮结果。父亲家书与退信交家属，由母亲决定如何读，原石补名继续征询其他家属。旧营地选择改变同伴告别对话。
