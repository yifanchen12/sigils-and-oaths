# 第三章《风过断脊》编辑与接入记录

0.16.0-dev，2026-11-06。沿用`chinese-novelist`串行流程：读角色档案与第二章结尾，列场景欲望/阻力，再写游戏JSON，最后按路线读稿和原生检查。以下是编辑自审，未获得外部读者评价。

## 场景中的变化

| 场景 | 当下所求与阻力 | 留下的变化 |
| --- | --- | --- |
| 镇口失控矿车 | 洛恩想拦车，芙蕾要求先撤到白石后；钟叔不肯让军队开主井 | 矿道仍被使用由事故呈现，撤回口令进入实际行动 |
| 莉珊的马具铺 | 莉希想用一封信解释离家，姐姐需要能据以安排家事的答复 | 两种选择都亲手交信；可承诺战后回访并先送信，也可明确无归期。姐姐的回应与晚间物件不同 |

| 绞盘争夺 | 杜骞要以公用绞盘抵押换船上人员下船，矿镇也有人急等欠饷 | 抢拆与布兵触发冲突，维洛无法靠一句担保解决；对手战败后仍留下实际需要处理的欠饷和被扣人员 |

| 营地 | 洛恩必须实际练习撤回，莉希要让家里按她真实的安排生活 | 羁绊由行动和边界推进，不以救援强制兑换恋爱 |

## 连续性自审

- 时间为河门出发后一天抵镇、过夜、次日井口与战斗、当晚收束。章末口信来自下山驿亭遇到的车夫，尚未当面核实港口情况，不让信使在没有路程依据的情况下往返港口。
- 主井八年前封闭，与长昼十七年前、芙蕾后来援护军官的右肩伤分开。上层检修廊只能背货。任何路线都不重开主井，不宣称井下未归者已获救。
- 队伍不进入地下新地图；守风口是在现有断脊隘口地表进行。工人卸配重、封廊等是战前后固定演出，没有伪造可操作矿工、护送AI或坍塌系统。
- 两种回信选择都有完整交信动作。希弥按前章约定在门外等；莉珊的信留在铺里。饰带仍由芙蕾保管，矿灯还给钟叔。修正了地址纸角凭空出现“姐姐”二字及将枪卫写成“打枪”的措辞。
- 检修路线留下维护与留守；外路路线留下休马、伤员和修路。没有藏在选择之后的无提示死亡判定。两路都能检视已卸货箱，避免将必要主线线索锁在一个道德选项里。
- 旧粮袋复用不能抹消赫姆前章的补填过失；新套管带旧图样不能证明原印复活。维洛当场承认自己资助过铸管线。第四章须兑现北船坞、返潮船与欠债，不再靠又一张公文无限推迟冲突。

## 检查结果与限制

- 17节点、97条文本，其中91段正文5,766汉字。承接前两章32种历史，两个二选一合计128条累计路径；每条第三章路线一战，单路线4,805–4,851字。全三章264段正文16,500字，连档案总已写22,058字。实际路线导出后，技能字数脚本得到4,805；导出和本文不重复计数。
- 1,520项纯模型检查通过：第三章1,045，既有跨章394，存储31，据点32，稳定游标18。覆盖失败不发战果、继承事实、三章历史恢复、两关配置、风口目标与计时中途恢复。
- 2,264项原生界面检查通过：实际新战役按钮、回看、两次跨章按钮、第三章选择、原生战前页/入场、菜单保存返回；261段对白与3段章末均在Windows渲染。常规与1008×700窗口检查文本/按钮边界；五张截图逐张视觉复查。
- 原生检查发现并修复：工具栏按钮被标题挤成竖条；旁白与选择页复用工事图标；目标进度只更新隐藏旧控件，实际绘制顶栏没显示；亮色地表上的目标“守”字难辨认。现有战斗Esc继续用于取消选择，菜单通过真实菜单按钮验证，没有为测试擅改快捷键。
- UI测试以剧情胜利夹具到达章末，并在据点放置合法关联部队检查进度。不是从初始牌组打通五场战役的证据。三章正常难度可通关、目标感知AI、全局平衡、外部阅读与完整退出重开仍待验；已验收叙事交付量保守维持档案5,558字。
