# 第八章《长昼的第八夜》场景设计

承接过水廊测绳移动、提灯熄灭。先撤人、量两端水位，才进入旧炉与塔基之间的现用设施。旧灾害的因果通过正在发生的回流、留下的旧接口和当事人的具体动作揭开；不把熄灯直接写成有毒气体或灵异证据。

| 场景 | 所求、阻力与变化 |
| --- | --- |
| 绳结以下 | 伊瑟要复核峰值，工班要下去找掉落的灯；余震带来的倒灌迫使停工，从岸上取样、两端同步测量。午前消息照约送回北街。 |
| 自己签过的图 | 当前工班拿的总图有伊瑟校录署名。选过clinic的队友已知部分，其他人现场听到；他不能等找到删峰者才说明自己的失职。测量时主动报出不确定区间并让本地水工复测。 |
| 炉坊余温 | 65岁旧水工桑岚认出维洛，先要求他把城外新管与塔基的连接指出来。老式第五夜关主阀确曾救诊所，但后加旁通绕过阀门，主塔未停；图样后来又被复制用于现今抽水。 |
| 临时选择 | 两种可执行的稳压方案：从外台隔离新支线，拆掉还可使用的一批管材；或从调压院启用空冷却池，丢掉池内寄存的旧模与料。都保留居民饮用支路，都不能永久解决塔基控制权。 |
| 阮衡的守机队 | 46岁守机管事阮衡认为急停会使北区井泵失压，且怕拆机后所有责任落到自己头上；他扣留手轮，命卫队强推总闸。玩家阻止实际军队重新压送，不能用对话自动获胜。 |
| 选择落地 | 外台方案在日陨地图两个公开据点连续驻守两次、12轮期限；调压院方案击败敌指挥官。战后再由工班实施隔离/排空，文字不冒充动态水位战斗。双方伤者收治，阮衡被解除指挥，拆除/材料损失保留。 |
| 第五夜与第八夜 | 桑岚在旧炉门旁重述亲历：第五夜停主阀，第六日师父被押在班房，第七日震塌后由她参与收殓。她在灾后第五年将旁通记为停用，只求保持居民水泵；维洛自己把修复图留给承包者的责任另算。父亲曾把地下人送到外廊，之后无确证，不靠新全知证人宣布生死。 |
| 给居民看的现场 | 居民代表看过仍运转的饮水支路，得知不能今晚就全部搬回。秦婶/余白的生活安排兑现，在城工班与居民翌日先看外台，远处代表收到邀请并抵达后再议正式会面。伊瑟把原始与删峰总图并置，旧人为决定和现在风险由同一次测量连起来。 |
