# 第九章《谁来签字》场景设计

承接第八章夜班水尺与发出的会盟邀请。次日先由日陨居民、工班和已经在城里的人看外台；林社与两城的正式代表数日后才抵达。先核对还在出水的支路、可修的材料、临时安置成本与守塔军的指挥关系，再讨论蓄能池。所有方案都保留居民饮水，均不能在签字当晚恢复整条河道。

| 场景 | 所求、阻力与变化 |
| --- | --- |
| 外台先看 | 秦婶要学堂按时开课、东街住户能有回去或另住的期限；工班长要能公开报出三次水尺。阮衡可答话，不能带原守机队重新掌闸。 |
| 算得出的代价 | 隔离新支线已损管材、工坊轮班；冷却池方案已损旧模与料、夜班仍耗薪。维洛的售产或租息负担沿前文保留，不能凭一句“我付”抹掉工钱。 |
| 等到代表 | 林社、守望与赤曜代表按路程抵达。赛菈有限共签只代表上游三处；艾琳无权单方替三方同意，维洛本人不代表全部赤曜工匠。会盟主持者由在城居民与工班临时推选。 |
| 三种可执行方案 | `joint`：本地工班与居民在场的三方轮值，先低流量试运、公开逐班水尺，异议会延长供水限制。`split`：先修独立旁路并把阀门分段，材料与工期最高、河道恢复较慢。`hold`：封主池一季，居民饮用支路、运水与定额旧井维持，种粮和工坊承受短缺。三者都列出付费与复查点。 |
| 父亲的缺口 | 艾琳凭旧担架架位置继续访查，只找到不能辨认身份的转运记录与一名当年抬担架者的有限记忆；不强行宣布父亲生死。可靠的下一处地点和具体问询对象进入第十章，不再只递一张无主文件。 |
| 下一道门 | 方案由有权限者分别签署，承认尚未执行。守塔军仍按旧紧急令守蓄能池上锁的检修门，下一章要先拿到可见的实际控制权；战争不因会场说理自动消失。 |

本章一处治理选择，三条分支各有不同的立即成本和关系后果，最终汇入共同的塔门危机。没有战斗夹具或虚构的水位模拟：具体夺门战留给第十章。新增背景为日陨外台会盟场景，保持既有青绿瓦、砂岩、二阶赛璐阴影与眼平阅读构图。验收分别核对图可达、旧事实、读档、原生画面、分支实际文字与字数；外部阅读评价另计。
