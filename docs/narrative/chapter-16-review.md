# 第十六章 · 桥上空桶：编辑与验证

第十五章的重铸与短套两路都继续送桶，塔没有通过高压验收。城东水车和修阀材料在桥上被旧护运合同拦下。白祁确实见过拔车销，却没有命令射轮；他仍须为扣车和桥上指挥承担调查。护运队索要的工钱与城东饮水分别核算，不用一车水抵旧欠。维洛的出售炉线或租息欠饷在对白中有不同回应。

本章新增16×12的东桥水车道和一场指挥官战。战斗胜利只解除封路，不能把送桶写成水塔验收。战后可以让护卫暂离桥上接受调查，也可以让一名自愿卸武装的护卫按实际搬桶车次领工钱；两路都保留拔销、射轮和旧欠饷的独立调查。谁对射轮发令仍待查，没有凭战斗胜利直接判定。

编辑检查重点：阿起的脚伤没有被说成直接殴伤；今夜桶车在两条结局的到达时刻不同；已付工资不能二次认欠，未付的一半也不能赖掉；北岸替件与新铸件仍按先前选择承担不同代价。对白尽量让白祁害怕手下散掉、维洛急于先写账、赛菈阻止替人写账，不让三人轮流发表同一种观点。外部读者审读仍未完成。
