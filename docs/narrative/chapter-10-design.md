# 第十章《门前两次响声》场景设计

承接第九章塔门内外两份相同的异常读数。第九章的三种临时供水方案已经由各方签字，但值守长尹纾手中仍是十七年前的紧急封门令。她听见阀后的第二次异响，不肯凭一张会场新纸让人越过警戒线；外台的水工也不能再等旧命令自行失效。

| 阶段 | 当场冲突与可见结果 |
| --- | --- |
| 门外对表 | 艾琳出示三方签押，尹纾出示旧令与当班读数。双方核对的是同一处震动，争的是谁可以碰内门、出事时谁能按停机手轮。居民运水车仍要过路，不能把他们写成战斗人质。 |
| 三种行动 | 共同轮值：艾琳率轻装接管队先夺两桥北岸，让本地水工与三方见证者随后入场；突袭预组，18轮。分段旁路：维洛率工程护卫开路，材料车只等16轮；突袭预组。封池一季：赛菈带混编饮水队护住两桥与旧井来路；均衡预组，20轮。三条方案各使用不同指挥官与限时，旧第九章选择已经影响实际关卡。 |
| 双桥战斗 | 新14×12日陨塔门地图。水渠横断地图数组第5、6行，只有左右各两格宽的石桥可过；胜利条件是在北岸 D9、K9 同时驻守两个己方回合开始检查，或击败值守长。玩家指挥官倒下、期限届满则败。普通部队照旧在任意友军相邻格部署，90秒行动回合照旧。 |
| 战后接管 | 尹纾仍有姓名、伤者和岗位，不在失败后突然认同新约。工班只接管外阀与两桥，先做关闭/复测，饮用支路持续出水；未写入动态水位模拟或未经实测的“全城恢复”。 |
| 后续缺口 | 外阀能停住下一次冲击，却暴露内阀杆旧裂纹与当年救援车的北岸接驳记录。父亲线索须在后续找到人证或可核实的转运终点，不用旧钥匙打开任何新锁。供水方案真正执行后的费用与居民返迁仍待后续章节结算。 |

本章是塔门外庭战役，不是全故事结局。胜利只设 `tower_gate_secured=true`，不改写第九章已签方案，也不凭战斗直接宣布水路安全。正文验收要求三方案及前章事实进入实际对白，战前目标与地图坐标一致，失败不推进剧情，胜后存读档可恢复。地图源图、提示词、尺寸和 SHA-256 见[`towergate-source.md`](../../assets/art/battlefields/towergate-source.md)。
