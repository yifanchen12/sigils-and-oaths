# 第七章《未送达的名字》场景设计

接第六章下山与东街换路预告。队伍次日下午抵达日陨，工班已经收到副本与骑使通知。旧诊所已成为八户十九人的住处，居民并不愿为一群查旧案的人再次失去住处。本章为九场战斗之后的转移、回访与营地篇，不新增战斗；搬家与水路施工按叙事发生，不伪装成未实现的护送关卡。

| 场景 | 所求、阻力与变化 |
| --- | --- |
| 拆不下来的床 | 秦婶要先知道床搬到哪里；艾琳一开口问旧名单，被请去抬眼前的床。北街学堂同意短住，工班停在隔离点等最后一户搬出，居民保留钥匙和回返权。 |
| 修船棚 | 余白不肯把未交的船丢下，洛恩险些擅自替他决定拆棚。大家用旧滑架移动船身，芙蕾坚持肩伤不能承重，洛恩照口令换位；让人物靠实际合作得以交谈。 |
| 四个旧称呼 | 余白和唐穗亲自答话，秦婶只提供自己照料过的部分。四人有不同去向，不写成四个等待主角救赎的名字。赫姆带着得到本人同意的回信回河门应答，离队有接送安排。 |
| 最后看见父亲的人 | 余白记得守桥人在第八夜往东侧过水廊接转移队；第七日塔已熄灭，第八夜是切断后的余震期。没有认尸或返家证据，艾琳不能据此断定生死。父亲的信仍是私人物品，不拿来换证词。 |
| 搬走以后 | 八户和修船所需物件实际移入安全处，秦婶给门上锁；工班才开始处理空出的支线。诊所饮水保留。棋庭补煤已由来使确认抵达，三夜旧储煤不被无限延长。 |
| 一晚同行 | 三选一营地支线：桥边台阶的洛恩与芙蕾；学堂临时诊室的伊瑟与米芮；高廊换班的莉希与希弥。玩家决定这一晚跟谁同行，不以救援或治疗换亲密，不设置统一好感分。 |
| 寄信与启程 | 艾琳给母亲写出实际找到与仍未知的部分，赫姆带信离队；三条夜间支线分别留下生活决定。余白翌晨带路到过水廊外，伊瑟比对现用回水线，接第八章现场与旧观测数据。 |

## 人物与时间边界

- 秦婶本名秦映，57岁；当年40岁，做工班缝洗活并照料转移者，后来替邻居写信。不是全知的档案管理员，也不是当年主治医师。
- 余白38岁，灾时21岁，现修船；四名被转移者之一，当时高热且头部受伤，初到诊所只能报出“阿白”。唐穗26岁，灾时9岁，现做炊食，名字经母亲后来寻来补全。叶成当时已老，灾后两年病故；第四人当年称阿蓼，长大后随戏班离城，现无可靠住址。不代替缺席者写授权或结局。
- 伊瑟灾时11岁，后来在学院录入旧数据，不可能是十七年前值塔工程师。承认自己在新档复核时的迟疑，与发现别人删去原始峰值是两件事。师父已故的是维洛，不把两条经历混写。
- 芙蕾右肩旧伤与断脊矿井分别保留；洛恩不能靠一场搬家治好她。莉希已交出给姐姐的信，姐姐的回信承接`letter_reply`；栗雨获得休息，不为每次送信无限奔跑。希弥的短笛与伊瑟的船画进入具体场景。
- 船工、病人、居民先有自己的决定。三条营地场景的关系进展以自愿、可以结束的陪伴呈现，未宣告固定情侣或强制恋爱。

## 接入与验收

唯一新增分支事实`camp_company`：`bridge`/`clinic`/`watch`，其余27项旧事实完整继承。三条支线各有独立事件与次晨回应；共用转移与父亲线索，选择不决定居民生死或额外证据。累计24,576条选择路线，每条仍九战。新正文以JSON为唯一源；单路线导出仅作审读，不额外计数。

测试分层：Python图审计保留全部累积路线；GDScript覆盖本章使用的所有继承显示条件组合、三选项与真实前六章历史，检查旧章末进入、新旧游标、磁盘恢复、回看和不凭空生成战斗。既有全六章历史验证仍保留，不为新增三条营地故事重复数万次相同文件解析。原生逐页确认所有新正文ID，实际三选项、小窗口和读盘；这不等于九战连续通关或外部文学审读。

增加四张原创眼平场景：日陨东街旧诊所院落、北街学堂夜间院落、同构的白天学堂、学堂临时病室。沿用现有日式线稿、赛璐璐色块与青蓝/暖砂金调色，源图完整保存，记录提示词与哈希，再做原生检查。
