# 第十一章《北岸有回信》设计

承接第十章莉希送往红瓦屋的信。此章不用战斗夹具推进人物线：艾琳本人见到旧调车员罗明，以及当年获救、如今负责北岸渡口维修的孟绫。两人从不同位置亲见守桥官抵达接驳所、返回渡头救人、身故及安葬；罗明保存的退回家书解释为何家属没有收到消息，但不能让他的多年沉默无代价地获得原谅。艾琳到埋葬处听他们重述，确认父亲的结局，决定先向母亲亲口说明，再处理公开记录。

本章的当下冲突是塔门内阀杆裂纹正在延长。艾琳不能重复父亲单人涉险的做法：她在伤痛中返城，明确让工班、诊室、居民和三方轮值各守一个可执行的岗位。第九章三种供水方案在撤路、材料车、运水车上有不同成本；第七章选过的同行对象在北岸有各自反应，不强制感情关系。结尾是可见的裂纹与有期限的施工准备，不宣布修复成功。下一章必须让玩家在战场上实际保护取回内阀件的工班，而不能靠此章一句对白完成。

两张新场景为北岸红瓦屋和旧索渡纪念处，均用原生 `image_gen` 参考项目自身绘景风格生成；源图、提示词概要、尺寸与哈希留在 `assets/art/narrative/chapter11-sources.json` 与 `chapter11-prompts.json`。它们只作为叙事背景，规则仍由既有 Godot 场景与战役数据决定。

验收：第十章真实终页能进入第十一章；所有条件正文可达且原生渲染；父亲线索由具体人物和地点兑现，不靠再转交新纸；存读档保留继承事实；失去塔门战不会跳入本章；正文审计无重复或不可达段落。章节字数与单路线字数单独报告，不把分支总和当玩家已读。
