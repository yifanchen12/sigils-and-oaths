# 第五章《水从哪里来》场景设计

接第四章天亮前的来使。两日路程后回到北支流，第三日午后代表按约到场议临时交接；众人同意先观察一夜分水与轮班，再于第四日午后正式表决。十二林社代表并未无故迟到。港口是较低处的补水取水口，新管把淡水送进高位调候蓄水池；林地受损来自旧池冲洗盐泥排入维修沟，并非海水逆流到山上。魔法降雨不能凭空洗去泥中的盐。

| 场景 | 人物所求与阻力 | 实际变化 |
| --- | --- | --- |
| 苗圃缺口 | 赛菈要接过水桶帮忙，苗圃的人拒绝让她拿饮水救苗；她此前要求等三方答复，等候已造成损失 | 居民让她先看排水沟，撤下她的代行旗，仍给队伍饮水 |
| 家门与旧伤 | 赛菈期望母亲瑟南支持；母亲曾因救下游难民失去席位，这次却支持重新表决女儿 | 母亲讲出十七年前自己的疏漏，要求女儿提出能执行的安排；不替女儿投票 |
| 高位池下 | 伊瑟要测水，渠首管事岑槐阻止他们动闸；池水供施工与高地苗床，排盐维修沟却通向居民支渠 | 发现新管冲洗旧池、泥中的盐被排下，原来回填的沉泥坑可以重新接通。岑槐有苗床和雇工生计，也瞒过排水去向 |
| 分水选择 | 余水只够本夜先浇苗或先清支渠。饮用水另留；不将活人饮水作为惩罚 | nursery先保苗、下游多等一夜并由队伍运水；channel先清沟、林社割弃一部分苗并改种，后续均兑现 |
| 林间岗战 | 岑槐要重新封住分水口，拒绝撤兵；赛菈指挥，艾琳只在获得许可后率队协助 | nursery路线在暮林地图F6/G5连续驻守2次、12完整轮；channel路线击败渠首指挥官。战斗不包含水量/盐度/NPC护送模拟 |
| 战后夜班 | 按选择把工人、桶车与余水送往对应地点；现有病株不能复活 | 水路处理真正执行，water_released=true；岑槐须面对林社问责，未自动获谅解 |
| 十二席 | 居民带着损失与夜班经历出席。赛菈要继续追关闸来源，但不再能独自代表所有林社 | 玩家在有限续任/交回代行印之间表态；前者获期限与共签约束，后者代表职权交给本地人，赛菈以见证者继续同行 |
| 母女与来信 | 留下/离开不是牺牲与原谅的自动交换。临时队伍也须让赛菈卸下照料所有人的负担 | 交代水轮班、母女未化解的裂缝、前章欠饷和补给；棋庭来信要求艾琳应讯，老师承认签过她父亲的停职令 |

新增说话人：瑟南，赛菈母亲，成年林社居民；岑槐，成年渠首管事；榆汀，成年苗圃照料者、此次受损户，参与议事但不是十二席投票代表。艾琳老师罗瑟只在正式来信中出现，本章不远程见面、不以复制签章认定全部旧案。阿妲仍是河门磨坊主，不把她改成暮林长者。

继承第四章全部19项事实，新增water_plan、water_released、grove_mandate、charter_copy。charter_copy表示取得施工令抄件与旧删款依据，不等于已经查明签发者的全部责任。两项二选一、每路线一战，五章累计2048条选择路径、每条八战。战败保持战前事实；续任表决只在战后发生。现有正文和存档稳定ID保留。采用既有暮林背景，专用林社背景与配角肖像待后续制作，不把旧图当新资产。

验收：正文冲突/动机/地理因果与物件去向审读；所有新字符串可达、真实旧结局继承、失败不发战果、四章旧存档进入五章、两种关卡/控制时限/计时恢复、原生页与分支按钮。模型胜利夹具只验证衔接，正常难度获胜另验。
