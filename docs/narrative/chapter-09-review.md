# 第九章：谁来签字

版本：0.33.0-dev。承接第八章的蓄能池处置。此章是战后议事，不插入虚构战斗；新的塔门冲突留给尚未制作的第十章。

## 这次写进游戏的内容

秦婶先要求确定东街住户在哪里住、孩子何时回学堂；工班长拿出三次水尺与欠薪簿。赤曜先到的是勘料员，正式授权和林社代表随后到达。会场没有由某个指挥官单方宣布结果。玩家从三套可执行的临时处置中选一套：

| 选择 | 立即效果与代价 |
| --- | --- |
| 共同轮值 `joint` | 本地水工保有停机权，三方只在齐授权后增流量；公开逐班读数，等候成本较高。 |
| 分段旁路 `split` | 阀门分段管理，施工增加两天并挪用北船坞材料；居民仍须暂住。 |
| 封存主池 `hold` | 饮用支路与旧井定额维持一季，工坊减班、上游苗床少水，运水车成为瓶颈。 |

第八章的隔离或缓压损失、维洛售产或租息的债务、赛菈的共签或见证身份、前章公开资料的方式都进入条件对白。艾琳继续追查父亲的转运线索，只得到有界限的证词与下一处实际询问地点；本章没有宣布其生死。三条方案各有不同签署和后果，最后汇合于守塔军持旧令封住检修门。

新增原创场景为[日陨外台](../../assets/art/narrative/council-terrace-day-v1.png)。以项目已有的学堂场景作**风格参考**，用原生 `image_gen` 生成并原样保存 PNG，未引用商业游戏素材。[最终提示词](../../assets/art/narrative/chapter09-prompts.json)与[源图、尺寸、SHA-256和处理记录](../../assets/art/narrative/chapter09-sources.json)在仓库内。
