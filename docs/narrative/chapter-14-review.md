# 第十四章《暗渠分水》编辑与验收

第十三章夜巡选择现在改变战斗开局。先查上游可获得一张临桥木架；先守塔则获得一张回流护印。两路都使用原创16×12暗渠地图和新的30张暗渠工班预组。两座原有石桥之外，河道中央起初没有通路；临桥只能在友军施法距离内、邻接可通行地格的水面逐格铺设。回流护印由手牌支付法力，伏设在友军身上，只在第一次敌方伤害法术或技能命中前触发，不会被普通攻击消耗。原有三种治理方案和借轴/留轴事实继续进入对白。

关卡目标是同时保护南岸量槽和跨河占住北岸闸位，连续两次己方回合开始；限22个完整轮次，也可击退敌指挥官。战后玩家在“先封石缝、东街继续送桶”与“按刻度送水、磨坊少磨半班并补粮”之间选择，分别保存`channel_order=seal`或`metered`。两路都保留塔内漏铆、新轴高压试验和明晨复测，胜利不等于供水系统修好。

剧情按`chinese-novelist`的冲突、动作、人物声线和悬念原则结合本项目写作基准修订。桥头木架滑落和未经命令的箭打断交涉；洛恩想越过桥沿拉人，芙蕾先拦后交盾；孟绫履行量水承诺，也追究自己弓手的擅射。未把误射直接写成蓄意破坏。东街与三村的供水代价在两种调水令下分别显现。章节仍需真人审读，自动检查不能代替读者判断。
