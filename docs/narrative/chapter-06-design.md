# 第六章《棋庭旧印》场景设计

接罗瑟来信。队伍完成林社交班后出发，第二天傍晚抵达古堡棋庭。兑现停职令原本、交接名册和老师的当面回答；本章不以又一张缺失回执结束。保持父亲失踪、维洛师父已故、长昼持续七日后切断地脉的既定事实。

| 场景 | 当下欲望与阻力 | 局面变化 |
| --- | --- | --- |
| 门外缴械 | 艾琳要带证人和原令入庭；罗瑟允许人入内，但让军队留外营，称原件仍在校验 | 三人进庭，队长分留内外接应，读者看到民居和中立场所被接管后的日常 |
| 训练廊 | 罗瑟希望先谈艾琳攻击河门守军；她要先看父亲原本，拒绝照旧坐回学生位置 | 老师亲手打开档库，停职令与交班簿兑现，不靠夺库得到第一批真相 |
| 父亲的去向 | 罗瑟想解释停职为保命；名册却显示父亲被迫脱去守桥身份后仍去救人 | 父亲拒绝在撤离表上确认已全员转移，随后随救援车去日陨东侧诊所；失踪仍未结案。备用钥匙仍是母亲保留的旧桥侧门钥匙，不作万能开锁物 |
| 新令的原本 | 三方要停止现行抽水；罗瑟承认本次借紧急条款临时恢复已删旧款，想保主塔和城内居民供能 | 原件证明签发责任；还有其他签押者与设施现状，不能用一个人的忏悔恢复水路 |
| 谁来听证 | 玩家决定立即向庭外公开有害条款与签发人，隐去无关家属/病患姓名；或保留原件给三方及工班代表闭门质证，限明早发布结论 | 公开带来即时支持与争夺，暂存引发门外不信任与代表监督；两条都实际实行，非善恶条 |
| 庭院夺权 | 留守队长陶因要扣留跨境冲突的带队者并继续次晨调候，担心旧楼居民断供；罗瑟起初要求等待，在亲见工班被拘后撤回口令 | 战场为军阵庭院，撤离居民留在外营。玩家以艾琳对抗陶因，击败指挥官解除守军封锁；罗瑟不被击杀、不会替玩家打赢 |
| 档库的交接 | 胜利后兑现公开/闭门处置，保管人常芷坚持原件不离馆，地方工班接手旧供能旁路 | 原件开放见证存放、留下可追责副本；停止未经共签的远程调候，日陨现场仍须安全换路 |
| 老师与学生 | 罗瑟想以独自留押替学生脱责；艾琳拒绝抹掉自己的军事行动，也不替他赎罪 | 老师留下接受审查并写明自己的现行指令，双方师生关系改变，父亲家信交给艾琳本人 |
| 夜间读信 | 艾琳想独自处理家信，同伴提出可选择的陪伴 | 获得父亲最后已知行踪与未署全名的伤员转移名单，下一章逐户接回具体的人，再前往日陨，不再追缺章公文 |

本章两项二选一：`evidence_council`为`open`/`witnessed`，`letter_company`为`alone`/`companions`。共用一场`c06_court`战斗，以艾琳、古堡棋庭、守备套牌对陶因；原始资源与90秒限制保持。新增`court_access`、`father_trail`为战果。继承全部23项旧事实，六章累计8,192条选择路径，每条九战。

新说话人：罗瑟，54岁守备总监、艾琳旧师；陶因，38岁棋庭留守队长；常芷，36岁档库保管员。NPC专用肖像后续制作，本章暂用古堡俯视背景。魔法不能让父亲遗物复现记忆，不能从印记自动读取动机。

验收为剧情因果和角色声线审读、分支继承/失败重试/存档与实际页面检查；正常难度胜利与连续通关单独验证。全文进入唯一JSON正文源，设计稿不计字数。
