# 第十一章《北岸有回信》编辑与验收

## 这章解决了什么

第十章只给出北岸接驳所和罗明的住址。第十一章让艾琳亲自到红瓦屋追问，罗明证实父亲把四名伤者送达；当年车上的孟绫补足他未看见的旧渡台一段。两人分别亲见遗体和安葬处，艾琳到无名石前确认。罗明的退信解释第一封消息为何没到，却不能抹去此后十七年的沉默；艾琳没有当场原谅，也没有替母亲拆信或决定碑文。人物线在此得到明确事实和一项家庭后续行动，避免再次用新纸条拖延答案。

塔门内阀裂纹的读数同时变坏。各方已分配水、材料、撤路和搬运岗位，但北岸库房的轴是否还在并未查明；下一章必须在实际规则中保护调查和运输，不可凭一句对白自动修好设施。第九章治理方案在返城成本上有三种条件段落，第七章同行关系在旧渡头有三组不同回应。

## 美术与界面

两张原创场景是[红瓦屋](../../assets/art/narrative/redroof-day-v1.png)与[旧渡头](../../assets/art/narrative/northbank-memorial-v1.png)。原生 `image_gen` 仅参考本项目已有背景的配色与线条，源文件原样保留；生成记录、提示词概要、尺寸和 SHA-256 见[来源记录](../../assets/art/narrative/chapter11-sources.json)。Godot 通过 `ArtLibrary` 加载它们，规则地形没有从图像推断。

第十一章119段条件正文全部在原生 StoryView 渲染，1361项检查零失败；大窗口截图见[红瓦屋](../screenshots/v035-c11-letter-01.png)、[旧渡头](../screenshots/v035-c11-riverbank-01.png)，并检查了[1008×700章末布局](../screenshots/v035-chapter11-end-small.png)。三种真实旧存档的终页截图：[共同轮值](../screenshots/v035-joint-chapter11-ending.png)、[分段旁路](../screenshots/v035-split-chapter11-ending.png)、[封池一季](../screenshots/v035-hold-chapter11-ending.png)。截图由原生界面测试生成，未作宣传合成。

## 可达性与保存

- 模型从八种先前历史与三种治理方案构成24条继承路线，全部到达本章终页；119段文本都有可达路径，12,627项检查零失败。前十章战斗在此模型覆盖中使用显式胜利夹具。
- 从三份此前**实际打赢第十章塔门战**的原生存档进入本章，每份通过鼠标界面阅读112段正文到终页；另起 Godot 进程都能读回。同组三方案写入717项、读回18项检查零失败。本章没有战斗。
- 从新战役开始的固定路线按实际战斗规则十一战全胜，继续读到本章终页；3,802项模型检查零失败。三处旧关玩家用只读取公开战场信息的测试策略，其他己方与全部敌方用生产 AI。详见[连续摘要](../continuous-v035.json)。
- [文字审计](../narrative-audit.json)无重复/不可达正文错误。本章去重正文6933个汉字；全书十一章加档案81,355个，固定路线实际读到60,044个汉字（不含未选分支、章末与档案）。
