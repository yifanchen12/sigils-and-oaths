# 誓痕伏阵：手牌、伏设与反制

0.29.0-dev增加8张原创牌，卡池由24种增至32种。新增预组「誓痕伏阵」可在遭遇战菜单直接选用，也可在组牌界面自行调整；战役仍使用各关既定军势。借鉴的是费用取舍、手牌伏设与反制关系，名称、图像和以下战棋效果均为本项目设计。

所有目标型新牌遵守友军3格、法师4格的局部施法范围。全局天气的旧规则保持原样。

## 一张陷阱如何结算

1. 从手牌选择陷阱与合法目标，先校验费用、施法范围与伏设位，再支付法力。非法点击不扣费、不丢牌。
2. 卡牌进入独立伏设区，每方合计最多2张。同方同一地格或同一保护对象不能重复伏设，不占普通部队上限。尚未触发时持续保留。
3. 主动移动与骑兵再机动按真实路径逐格检查。触发地格陷阱后，阵亡或定身会中止剩余路径；存活且未定身则继续。友军经过、部署、击退、换位不触发地格陷阱。
4. 普攻先确定枪兵援护，再检查实际承伤者身上的回誓屏障，之后结算伤害与普通反击。精准射击属于普攻；法术、部队法术技能、反击、疲劳不触发屏障。
5. 陷阱在结算效果前从伏设区移除并进入弃牌堆，避免再次触发。保护对象离场，护军陷阱也失效弃置。

己方能看到紫色「伏」标记。对手只知道伏设数量，日志、目标闪光、施法者动画与合法目标集合均不公开敌方陷阱位置或身份。敌方有伏设时，攻击预估注明没有计入隐藏陷阱。AI通过公开局面判断伏设和探查位置，不读取敌方陷阱内容。

## 兼容与验证范围

战斗快照升为v3，保存伏设区、原卡牌实例与保护对象编号。v1/v2战斗只在原有卡牌、预组、地图等规则签名完全吻合时接受新增卡池迁移；旧局的抽牌顺序、随机状态、资源和战果不变，迁移不会凭空增加陷阱。未知规则或未来版本仍保护原档。

规则测试覆盖手牌扣费与牌区守恒、路径中断、骑兵再机动、天气、援护优先级、法术绕过护军陷阱、保护对象死亡、解缚不恢复行动、群疗预估、探查空放、隐藏信息扰动与真实旧快照迁移。

预组初始含16张部队、14张非部队牌。固定种子的自动对局用于找非法操作、长局、触发缺失与存档问题，不能代替真人体验或宣称数值已经平衡。当前八章连续通关和十万字目标仍未完成。
