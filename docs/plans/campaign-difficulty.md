# 战役难度与关卡节奏

1. 用 0.51 的战役路线定位桥头、交接所、暗渠和东桥的长局。比较开局支援，以及能引导前线部署与守桥的驻守点。用相同关卡种子回测标准与剧情难度。
2. 战前简报支持选择难度。剧情难度增加开局法力和护盾，限时关卡多三个完整轮次。通过试跑调整原本拖长或失利的战斗，在桥头、港口、闸口等地点设立能争夺的据点。界面根据实际规则显示坐标与期限，单个行动回合仍为 90 秒。
3. 难度写入进度及战中档。通过失败重试改变难度，重建对应开局。验证旧档、章节重走、保存失败和战中退出重开。
4. 从首章用固定剧情选择连续跑两档难度，记录胜负、行动数量和未改善的样本。以实机小窗口复核难度选择与战斗目标，再导出并校验 Windows 包。
