# 0.7 战场表现

范围：只改表现与信息展示，不改地图格子、行动规则或卡牌数据。

1. 全图展开时，将棋盘左侧空白用于原生人物/卡牌详情浮层。悬停单位、选牌或选择英雄技能时显示相应肖像、状态与规则；右侧显示敌方肖像与公开法力、手牌数量、技能冷却和天气剩余回合。缩放使空白不足时隐藏，鼠标事件穿透，绝不遮挡可点击格。不显示敌方手牌内容。
2. 地形保留同一规则坐标，在连续草地/砂土/石板上增加邻接颜色过渡、工事阴影、高地边沿与河岸石堤。水面在港口也持续缓慢流动。
3. 验收：详情内容跟随选择、悬停与回合更新；缩放后不覆盖棋盘且不改变战斗状态；菜单不透出详情；三种窗口尺寸、既有203项UI流程与截图复核。地图路径与战斗规则不改变。
