# 大地图与镜头迭代

用户已明确选择：扩大格子数量和显示区域，加入缩放与拖动。优先级高于自定义组牌。

1. Battle 从地图行数据读取 width/height；合法格、法术范围、坐标名和 AI 寻路使用实例尺寸。旧 8×6 布局保留为隐藏回归测试地图，不再展示在游戏地图菜单中。
2. 六张正式地图重绘为 12×10，面积为原来的 2.5 倍；手工布局保留旋转公平、出生点互通和明确主路/侧翼。地图不机械拉伸，桥梁/山隘/堡垒构造重新布置。
3. BoardView 维护缩放与平移；滚轮以鼠标位置为缩放中心，中键或 Alt+左键拖动，按钮一键适配全图。格子转换、路径与范围都使用相同变换。限制平移，避免把地图拖丢。
4. 原生战场工具条提供缩放与展开视图。展开后隐藏两侧情报和大手牌区，扩大棋盘可见空间；结束回合、英雄技能、退出展开仍可直接操作。Tab 切换展开，Home 适配，+/- 缩放。
5. 验收：六张大地图对称/互通与完整对局；缩放前后命中一致，拖动不提交行动；适配/重开正确复位；展开/恢复不改变战斗；实际图形操作与三种窗口尺寸检查。
