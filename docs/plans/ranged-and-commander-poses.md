# 远程部队与指挥官动作

目标：为弓手、法师、医师及艾琳/维洛/赛菈各补三张准备、施放、收招姿态，连同上一轮近战角色组成九角色动作家族。接入普攻、反击、单位技能、指挥官技能及法术卡的实际施法来源。伤害、消耗、射程与规则结算不变。

1. 每个角色单独生成3×1透明原图，以已有原创站姿锁定身份、服装和赛璐璐风格。验收三帧非重复、武器/长裙完整、透明间隙可切片、成年正常比例、棋盘尺寸可辨识。
2. 按实际透明间隙切片、记录脚底锚点，保持原PNG完整。沿用上一轮无mipmap导入方式，保存完整提示词、来源、alpha和哈希。
3. Main仅给展示数据增加施法者ID；Board使用有限时间线显示其姿态。普攻优先自身战斗时间线，施法结束/新动作/菜单/重开清理，不能留旧角色。天气与法术的全场/范围规则不变。
4. 验收九角色图集、真实输入下的远程出手/反击、两种单位施法与三英雄技能、法术来源、死亡和重开；核对规则状态、RNG与数值一致。原生截图/录像与针对性回归通过后更新现有PR。

技术：Godot 4.7.2二维棋盘；新图逐角色三帧，原生AtlasTexture按检查结果分区，不假定生成网格精确等宽。按源图脚底对齐且等比绘制。此阶段仍为关键姿态，不声称完整行走循环或全屏战斗过场。
