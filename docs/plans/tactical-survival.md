# 战役通关与部队生存判断

本轮先处理已暴露的决策问题，保持卡牌/地形/初始资源/关卡期限不变。0.17.0-dev 的八关固定种子诊断中，首章桥关和两个第二章守桥关均失败；该结果只能指向需分析的路线，不能认定玩家无法通关。

1. 重放失败动作，检查部署点、生命、法力与驻守中断。验收：保留原结果，指出评分中可复现的缺陷，不靠改资源取得胜利。
2. 补充公开棋盘的部署/移动风险与医师行动选择。验收：脆皮避开明显射程、寻路遵守实际地形/阻挡、下一回合定身状态正确、治疗有价值时不先耗掉行动微量攻击、决策不改棋盘或读取隐藏牌。潜在移动风险是启发式权重，不是完整敌方回合模拟或概率。
3. 同策略八关与谨慎玩家策略三目标关分别运行。验收：每组全部胜负、完整合法动作、计时和性能均记录；组间结果不混算为胜率，不用调参后的固定种子成绩声称平衡。首轮过度保守造成长局和风口失败，需如实记录舍弃原因。
4. 独立重放、两个原生进程的敌方回合退出/续战、实际胜利到不同剧情。验收：从正式初始战局进行，不放置部队或更改牌序；完整状态和磁盘记录一致。前章入口夹具与已实际打完的单场明确区分。
5. 保留仍失败路线，更新说明、发行状态和下一步通关缺口。全战役五战连续通关、外部试玩与人工平衡仍是独立门槛。
