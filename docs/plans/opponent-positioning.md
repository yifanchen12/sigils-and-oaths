# 0.8 AI站位与安全抽牌

目标：改善可观察的战术选择，仍只使用公开棋盘和AI自己的手牌。规则、卡费、英雄数值和地图通行不变。

1. 弓手等远程部队比较移动后的实际伤害/射程与反击，优先在同一回合拉开距离后开火，避免无意义贴脸。
2. 所有攻击评分考虑非致命反击的代价；仍优先立即击败敌指挥官，不因保全单位错过获胜。
3. 医师站位考虑邻近伤兵的恢复价值；伤兵适度偏好遗迹或赛菈的森林，不让恢复压过明确获胜。
4. 抽多张牌时预测牌库不足带来的疲劳，避免为了抽牌主动杀死己方指挥官。保持牌库/手牌区域与非法操作原子性。
5. 验收：可复现棋盘场景验证远程拉开后合法攻击、医师支援、立即获胜优先、安全抽牌、无隐藏手牌依赖及choose不修改状态；再运行完整对局与镜像诊断观察是否卡住或过度消极。
