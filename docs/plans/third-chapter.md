# 第三章：风过断脊

本章接第二章末芙蕾握住地图的手。按`chinese-novelist`串行写作；先场景设计，再游戏正文，再连续性审读与接入。

## 场景与人物欲望

1. 断脊镇入口：一辆无马矿车滑出旧坡，芙蕾按旧救援口令拦住想往前冲的洛恩。封闭矿道仍有人用，先以事故呈现疑点。钟叔想保住镇子的修路收入，却不许军队强开主井。
2. 马具铺：莉希想留下信就走，姐姐莉珊要的是一个可执行的返程答复。希弥按前章约定留在门外；不偷看、不替她道歉。玩家选择约定战后回访，或交信但不许诺日期；两种都交信，姐姐的回应不同。
3. 旧井口：芙蕾承认八年前在井下发过撤回口令，主井后来封死；工衣饰带来自那次救援，右肩军伤是更晚另一件事。钟叔参与封井，并非一位随时替她开解的导师。上层检修廊由人背货，不能通粮车；河门回执上的运粮数量因而可疑。
4. 运机争执：掌运官杜骞要拆走镇上共用的绞盘，借新合同抵自己和手下的欠饷。矿镇有人替他搬货；阻力来自生计、旧关系与武力，不靠一句“奉命行事”。
5. 路线选择与战斗：守住地表两处通风口，给工人留下回收检修廊和绞盘的窗口；或者封住检修廊，沿山脊攻击押运指挥。前者为两点连续驻守的限轮战，后者击败指挥官。使用现有断脊隘口规则地图，地表作战，不伪装成可走的地下新地图。
6. 余波：前者保住小宗物资通道、留下检修负担；后者失去近路、保留封井界限。两路都付出已说明的代价，不卡关键线索。货箱中是港口生产的调候套管，粮袋与铅封被复用。维洛必须认出自己资助过的制造商，而非再隐瞒一个新秘密。
7. 夜间收束：芙蕾与洛恩练一次真正执行的撤回口令；莉希的回信选择留下不同回应；钟叔留镇，赫姆仍随行并记得要回河门回答补单。结尾把队伍引向碧潮港的船坞，以及维洛尚欠的债。

## 可观察后果

- `letter_reply=return/unscheduled`：两种回信行为、姐姐的晚间回复与后续羁绊事实。
- `pass_route=vent/ridge`：不同关卡配置、地表目标、战后通道条件与次日安排。
- `supply_route=maintenance/long_road`只在对应战斗获胜后写入。
- `mine_cargo=true`、`letter_delivered=true`只能由实际剧情路径写入；继承前两章九个事实，不改旧章。
