# 完整绘制地图

用户再次明确地图过于简陋。当前问题是逐格地面、几何管线道路与盆景式地形物体，没有完整场景的连续构图。

1. 先完成暮林边境一个代表性目标。由Godot输出没有UI/棋子的真实12×10地形导图，作为位置约束；使用原生imagegen将其绘制成日式战棋环境。验收：森林、道路、高地、山地和两处遗迹与规则坐标对应，路线中央可见，人物仍醒目。
2. 图像作为静态地图美术层，规则与可交互格子仍来自Battle。动态造路/筑垒用原生层覆盖对应地格。验收：缩放/拖动、部署、寻路、战斗预估和地形卡不受背景替换影响。
3. 调整网格、地形标识与环境动画，使全图像场景、操作时可读。保留可切换的地形网格用于查看和QA。验收：实机原比例检查，不能以概念稿代替。
4. 代表图通过后，扩展六张生产地图；不复制参考游戏素材，保存源图、提示词与位置导图。验收：各图地貌和战术位置可核对，图鉴菜单缩略图同步。

先保持全部地图规则数据不变，避免以美术重做掩盖通路变化。若生成图偏离导图，先修正或不启用，不能用漂亮背景制造错误地形暗示。
