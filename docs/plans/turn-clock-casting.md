# 回合时限与施法范围

用户要求：每轮有出牌时限，法术不再全图施放，应受到兵种周围范围限制；人物改为成熟正常比例，学习日式奇幻时装，人物统一成年。

用户随后已明确确认：每个行动回合 90 秒；普通友军提供 3 格、法师 4 格施法范围，天气仍为全场效果。

- Battle 管理剩余时间与超时回合交接；倒计时不由 UI 自行判定合法性。主场景负责每帧传入时间、暂停菜单与启动新一方 AI，防止旧 AI 协程越过回合。
- 本地战前菜单、规则和图鉴暂停倒计时，与现有 AI 暂停行为一致。没有联机计时或反作弊设计。
- 单位存活即提供施法范围，包括新兵；使用与移动/攻击一致的曼哈顿距离。目标型伤害、控制、地理牌必须处于友军范围并满足本身条件。
- 抽牌、临时法力、天气与天气清除为全局无目标牌。范围法术只验证中心，周围溅射按卡面结算。
- 指挥官技能以指挥官为中心，艾琳 3 格、维洛/赛菈 4 格；赛菈只治疗范围内友军，仍抽 1 张。换位要求目标在己方指挥官 3 格内，避免以远方单位为施法点瞬移指挥官跨越全图。
- UI 同时显示淡色施法覆盖和有效目标；AI 从同一个合法行动集合选择，不绕过范围。
- 验收：超时一次性交接、重开复位、暂停/恢复、AI 协程取消；边界内/外施法、法师额外一格、杀死施法支点后覆盖收缩、非法施法状态不变、英雄局部治疗、完整对局与真实 UI 检查。
