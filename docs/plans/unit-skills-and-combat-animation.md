## Capability and file boundaries

- 规则：scripts/battle.gd负责技能目标、检查、费用/次数/回合清除、援护选择、实际普攻承伤和反击；data/cards.tres记录六技能名称与说明，scripts/rules_text.gd同步玩家规则。
- AI：scripts/opponent.gd评分技能价值与实际被援护目标，遵守同样动作合法性。
- 操作与预估：scripts/main.gd添加所选部队技能按钮、目标模式、提示与预估；scripts/board_view.gd绘制技能范围、援护状态与动画。scripts/battle_peek.gd沿用现有present接口。
- tests/test_unit_skills.gd覆盖六技能、援护与非法操作原子性；tests/test_forecast.gd补援护预估；tests/test_ui.gd保留原交互并加入技能入口验证；必要时独立动画窗口检查输出实机截图。
- README.md/README_EN.md与docs/validation.md同步已验证功能。
- 不改地图、英雄、套牌配置和现有生成美术原图。不引入联机、全屏战斗过场或额外兵种。

## Interfaces and invariants

- unit_skill(unit)->Dictionary：按兵种返回名称/描述/费用；commander无部队技能。
- skill_targets(unit)->Array[Vector2i]：仅当前行动方、非新兵、未攻击、技能未用、法力足够时列合法格。非法输入返回空。
- apply_action({type:"unit_skill",unit_id:int,target:Vector2i})->Dictionary：全部验证通过才扣1法力并标记已用；错误返回ok:false，不修改战斗状态。
- 步兵坚守：自身护盾至少3（沿用不叠加护盾）；已有3以上时不可浪费使用。
- 枪兵援护：开启至下次己方回合开始，拦截上下左右相邻友军（包含指挥官）的主动普通攻击。按守卫id选择一个有效、存活且非被定身的守卫；无援护链。直接攻击枪兵仍由其自己承伤。
- 援护使用守卫实际所在地的防御/地形，反击从守卫原位按其射程判断；不永久位移，不拦截法术、反击或医师治疗。攻击者仍先以原目标验证射程。守卫阵亡/离开邻接范围后立即失效。
- 骑兵再机动：已移动、未攻击时选择最多2点加权移动费用的空地；定身时不可用。保留攻击机会，累积实际移动格数用于原有冲锋。
- 弓手精准射击：按原普攻射程（含高地/浓雾）攻击，伤害+1；遵守援护与反击。
- 法师星火：自身2格内敌军，基础3火焰伤害，按天气加减；不受指挥官首张火焰牌被动加成，不被援护拦截，护盾正常抵挡。
- 医师急救：自身2格内受伤友军，恢复3生命至上限。
- 六技能均1法力、每单位每己方回合最多一次、新兵不能用；除骑兵外均结束该单位移动和攻击。
- 普攻预估返回实际承伤目标、目标生命损失与攻击者生命损失；规则/UI/AI共用援护选择，不修改状态或RNG。
- 动画读取动作前快照与规则结果；规则即时结算，表现不改坐标/血量/RNG。援护以短暂视觉拦截并归位；菜单/重开/连续动作清理旧表现，禁止动画结束回调再次扣血。克制命中显示提示。
