# 0.10 界面重做

目标：消除调试面板观感，建立与日式赛璐璐人物一致的完整游戏界面。

1. 战前页改为角色主视觉与战场选择双栏。验收：三名指挥官、六张地图、组牌与出征均可鼠标操作，选择状态明确。
2. 手牌改为图像卡面，统一金属边框、象牙白铭牌、费用宝石与兵种徽记；展开战场也保留图像手牌。验收：八张手牌完整显示，悬停详情、费用不足与选中状态清楚。
3. 战斗界面统一深蓝底、金边和浅色情报卡，加入真正可见的菜单入口。验收：地图仍比常规面板模式大，缩放拖动、90秒计时、技能与结束回合正常。
4. 组牌页沿用卡框并补充独立套牌摘要和费用曲线。验收：24种牌增减、保存、取消和跨战局使用不回退。

实现只改展示层及美术映射；规则由既有 Battle 模型负责。运行原有规则与实际窗口交互测试，检查1440×1000和窄/宽窗口截图。

验收结果：257项Windows交互检查通过；基础76、计时/施法28、套牌39项通过。原生截图已查看并收入docs/screenshots。规则模型未改动。
