# 0.12.1 战斗反馈完善

用户继续授权迭代。沿用0.12已批准的六技能、克制与动画规则，仅完善预估和表现，不新增兵种、费用、范围或伤害规则。复用godot-animation与game-feel的表现/规则分离方式。

1. 修复胜负面板过早盖住最后一击。BoardView提供是否仍有一次动作表现待完成的查询；Main等待当前动作的有限时长后显示已结算结果，无再次伤害或改变胜负。暂停/菜单/重开仍清理表现，不留下延迟回调操作新对局。
2. 为目标型部队技能、卡牌伤害/治疗/护盾和英雄技能添加只读预估，复用Battle现有合法目标、spell_damage/fire_damage、护盾及治疗上限。包括范围伤害实际受影响名单；预估不改变状态/RNG，切换/取消清除高亮。
3. 攻击、治疗和防护采用不同原生特效；普通法术牌也有施放轨迹，火环有范围扩散。施法来源从合法友军覆盖中确定，仅作为视觉起点。增加反击克制提示。

改动scripts/main.gd负责选择、预估与结果显示；scripts/board_view.gd负责效果与有限播放状态；必要时新增纯只读预估脚本以复用计算。规则模型battle.gd、data/*.tres及美术原图保持不变。测试以实际应用动作前后对比为准，不用预估复制实现来判断正确。

验收：技能/法术预估对比真实扣血/治疗/护盾，天气/被动/溅射与范围边界正确；最后一击结算立即生效但面板等动画结束，重开与菜单没有旧回调；真实窗口截图及原有UI/预估/技能检查通过。仅扩大受改动影响的验证范围。

2026-10-26已验收：只读数值预估134项、实机反馈56项、原UI257项、普攻预估113项和技能窗口51项通过，合计611项。本轮没有改变规则模型和配置。新增EffectForecast供文字面板、人物预览与棋盘增减条共用，避免各处重复计算；BattlePeek改用原生聚焦裁切保留人物脸部。Godot录制约19.7秒演示，含预估、分类法术效果与最后一击。详细日志和边界见../validation.md。
