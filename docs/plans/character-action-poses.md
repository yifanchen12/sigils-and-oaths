# 人物出手姿态迭代

范围：沿用现有成年日式赛璐璐人物，为战斗增加蓄力、出手、收招三张关键姿态。先验收步兵、枪兵、骑兵，再决定是否扩展远程与指挥官。规则、伤害、卡组与地图不变。

1. 生成近战三兵种 3×3 真透明原始图集；逐行保持角色身份、装备、朝向和脚底基线。验收九格完整、无串格、非重复站姿、缩小到棋盘仍可辨识。
2. 使用 Godot AtlasTexture 读取原图，接入普攻、援护与反击时间线；结束、死亡和取消后恢复正常显示。验收规则状态完全不受展示影响。
3. 通过实际窗口截图、动画录像与针对性测试验证，记录来源、提示词、尺寸和局限；更新现有 GitHub 分支与 PR。

技术约束：Godot 4.7.2 / 2D；原始 PNG 保持完整，运行时切片。正常棋盘约 50–90px，透明格内保留武器和披风边距；沿用现有白金护甲、青绿织物与清晰勾线。当前阶段不是完整行走循环。

制作调整：九格合并请求等待超过二十分钟无返回且没有输出文件，已取消，不计为交付。改为每个角色一张 3×1 原始图集，先以步兵作风格种子，再扩展其余兵种。原九格设计提示保留为 brief；实际成功调用另行记录。

实现结果：三组 v2 原图已接入。生成的分格并非严格等宽，实际在透明间隙采用 x=724/1560 两处原生切片，保留长剑/长枪，按源图脚底锚点和每角色统一比例绘制，不拉伸图像。三种兵各有三张姿态；普攻与反击按各自时间线播放，枪兵援护使用举盾帧，动作图朝向对手，阵营/生命文字不翻转。站姿与其他角色保留原路径。

验收：九帧原始 alpha、边缘留白、切片、差异与锚点检查通过；放大与72像素对照图、实际棋盘截图已查看。Windows 原生录制160项通过，含左右攻击、援护、反击、规则状态不变、重开和死亡淡出。录像1114帧/60FPS、18.57秒。整体界面257项、法术反馈56项通过，详细日志记录在 validation.md。完整行走循环、远程与指挥官的姿态仍待后续制作。
