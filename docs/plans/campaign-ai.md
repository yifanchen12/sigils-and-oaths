# 战役目标AI与合法对局验证

0.16.0-dev之后的本轮范围：敌军要理解双点驻守，而非只向指挥官走；以真实关卡初始牌组、法力和地形运行并记录完整合法行动。采用`game-ai`技能的utility scoring与逆向寻路，沿用现有规则权威，不引入行为树框架。

1. 保存当前AI作为比较基线，运行八个已注册关卡。记录胜负原因、行动数、回合、驻守进度、决策时间和非法行动；失败也保留。
2. 新AI只读取自己的手牌、公开棋盘/目标/期限。攻方占据未控点并守住已有点；守方争取至少阻断一点。攻击看实际援护承伤，击退看真实落点，不能把定身当作移出目标。已经能直接击败敌指挥官时优先结束战斗。
3. 针对抢点、留守、挡路绕行、最后一轮阻断、援护、击退、范围伤害、隐藏信息和决策无副作用运行回归。普通无目标遭遇战继续通过原有AI检查。
4. 再跑同一组真实初始关卡，保存所有行动和规则状态，独立重放核对。能获胜的记录仅证明这条合法路线可行；失败不直接解释成人类无法通关，自对弈不代表平衡。
5. 将可行记录接到原生战役流程，验证真实结果→剧情/保存与重开。UI按钮检查、规则重放和从初始局面获胜分别报告，仍保留外部试玩/可玩性与完整平衡门槛。

不在本轮调整卡牌数值或放宽驻守期限来迁就AI。若发现关卡无法达成，先定位规则、寻路和决策原因，再根据证据提出修改。
