## 可迁移的视觉规律

- 明亮的日式奇幻；草地青绿、水面偏青蓝，石墙与道路用浅暖灰。大色块先分清地貌，细节留在边缘和少数焦点。
- 地图是连续空间：道路沿相邻地形衔接，河岸连接，桥梁实际跨越水面。避免每格重复一张高频纹理照片形成拼贴。
- 略俯视的地形与建筑带可见侧面：树冠、岩山、城墙形体简洁，受光面清楚，阴影方向统一。
- 行动范围使用可辨的透明蓝/红格，与场景色彩分开；单位轮廓与环境不混淆。
- 角色偏日式插画，全身战场形象比例较小，头脸与武器轮廓在小尺寸下清晰。
