# 断阵重术的牌组替换对照

使用 0.42 的对战规则，沿用 0.41 暮林边境、双桥河谷、断脊隘口三张地图及三个种子。双方使用艾琳和正式对战 AI，每图交换一次座位，依正常流程抽牌、增长法力和行动。均衡军势固定为对手，未替换基准的正式牌组。 [0.41 基准](warfront-matchups-v041.json)

| 断阵重术配置 | 取出 | 换入 | 指定对局结果 |
| --- | --- | --- | --- |
| 正式牌组 |  |  | 6 胜 0 负 |
| 换掉十费牌 | 天炉坠火 ×1 | 战地工事 ×1 | 5 胜 1 负 |
| 换掉部分射程与直伤 | 开窑火矛、星纹抄法师、高台破雾弩各 ×1 | 逐风骑士、晨光医师、战地工事各 ×1 | 6 胜 0 负 |
| 换掉五张范围牌 | 天炉坠火、澜潮冲阵、崩纹震击各 ×1，雾棘封径 ×2 | 陨火之环、星火箭、战地工事、晨曦祷言、寻痕灯各 ×1 | 5 胜 1 负 |

三组替换共完成 18 局、4,229 个合法行动。较少范围牌时仍保有明显优势。每组只含三个种子，牌表变化也改变了抽牌顺序，因此结果只能定位复测范围。其他预组、阵型决策和真人强度还需单独验证。替换只在测试进程内生效。 [完整逐局数据](warfront-balance-probes-v042.json)

```text
godot --headless --path . --script res://tests/benchmark_warfront_ablation.gd -- --probe=capstone --deck=frost_engine --report=user://warfront-capstone.json
```

将 `--probe` 改为 `early_reach` 或 `area_core` 可重跑其余两组。
